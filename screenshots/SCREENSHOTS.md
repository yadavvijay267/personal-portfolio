# Screenshots

Screenshots go here. Take them after the first deploy:

1. `hero-light.png` — hero section, light theme, daytime greeting.
2. `hero-dark.png` — hero section, dark theme.
3. `projects-filter.png` — project grid with a filter active.
4. `mobile.png` — mobile view (390px wide) with the drawer menu open.

Tip: in Chrome, DevTools → Device toolbar, or use `python3 -m http.server`
and screenshot the running page. Keep images under ~300 KB.
